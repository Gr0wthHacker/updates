Built TaskPilot a memory. Drop text, a URL, or a file into the new memory inbox and the AI summarises it, tags it, pulls out the entities, and links it to anything related already in the system. Pull it back via search, tags, or just scrolling.

The point is to stop losing the half-formed ideas, screenshots, articles, and meeting notes that pile up everywhere else. Capture is one hotkey. Recall is one search.

Local-first. Works at scale by design — drop ten thousand items in and lookups still come back instantly.
