I run six businesses. Every Claude session I open with one of them in mind starts the same way: where am I, what was the last decision, what's the next move. Re-deriving that context every time costs minutes I don't have.

So I built a shared status layer. Every business has a live "where things stand" doc that pulls from open work, recent decisions, sessions I've had this week about it, and explicit notes I or any AI session log along the way. Open a fresh session in a related project and the status is one ask away.

The compounding effect is what I'm betting on. The more sessions feed it, the better the next session starts.
