TaskPilot already turned high-level work into approvable steps. Now it can run the approved steps too. A background runner picks up queued agent tasks, executes them, and feeds the results back without anyone watching.

The trust dial is mine. Some tasks are still "ask before doing anything." Others are "go." When the runner finishes, results show up in a review feed if I asked it to check in, or quietly land done if I told it to ship.
